# rmcp-release-demo

A test MCP server whose purpose is to exercise distributing a Rust binary to users through Homebrew and a
curl installer.

## Language

**Supported install method**:
An install method that the README documents for a platform and that the post-release check verifies on that platform after every release. A method that merely works, such as Homebrew on Linux through the formula's Linux section, is not one.
_Avoid_: available install method (covers methods that merely work)
